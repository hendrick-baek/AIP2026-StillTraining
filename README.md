## 핵심 기여

### 1. 보상 결함 진단 — “계수가 아니라 함수 형태를 수정”
정책이 조준을 포기하고 표적을 관통하는 문제를 보상 기울기 직접 계산으로 분석했다.
`r = w·f(조준)·g(거리)` 구조에서 가중치 w는 두 기울기의 비율에서 약분되므로 w를 8배로 키워도 행동이 바뀌지 않았다.
조준항의 **지수를 2 → 4**로 바꿔 정조준 근방의 기울기만 선택적으로 키웠다.

| 지표 | 수정 전 | 수정 후 |
|---|---|---|
| 조준 오차 ATA | 50° | **3°** |
| WEZ 체류 | 6.2 스텝 | **208.2 스텝** |
| 추락률 | 48% | **2%** |

학습 중 발생한 보상 결함을 **경계 생성 / 부호 반전 / 기울기 소멸**의 세 유형으로 정리했다.

### 2. 조종 명령 생성기 결함 수정 — 기동 성능 회복
교전 직후 상대보다 늦게 기우는 현상을 추적해, 배포 제어기의 결함 2건을 찾아 **3행 수정**으로 해결했다.
- `sin(UTAngle)`이 180°에서 0이 되어 가장 급히 돌아야 할 때 롤 명령이 사라짐 → `sin(UTAngle/2)·2`
- 롤 명령 제곱(expo)으로 명령이 항상 감쇠됨 → 제거

| 지표 | 우리 | 상대 |
|---|---|---|
| 선회 반경 | 973 m | 999 m |
| 선회율 | 12.2 °/s | 12.2 °/s |

리드 추적의 조준 오프셋이 특정 조건에서 37°까지 벌어지는 결함도 찾아 3° 상한으로 막았다.

### 3. 전술 노드 자체 설계
배포본의 기동 노드는 `Task_Empty` 하나뿐이었다. 태스크 6종과 조건 2종을 직접 설계했다.

| 노드 | 역할 |
|---|---|
| `Task_Pure` / `Task_Lead` | 순수 추적 / 미래 위치 예측 리드 추적 |
| `Task_BreakCircle` | 대칭 시저스(AO 160°+ 3초 지속) 탈출 — 선회 평면 전환 |
| `Task_PostMerge` | 교차 직후 적 꼬리 뒤를 조준해 되돌아서기 |
| `Task_InitialDive` | 저고도 유인용 초기 강하 (강하각 55°) |
| `Task_Recover` | 표적 무관 45° 상승 고도 회복 |
| `DECO_AltitudeCheck` / `DECO_ElapsedCheck` | 절대 고도 하한 / 경과 시간 판정 |

### 4. 상대 분석 기반 저고도 유인 전략
기동 성능이 대등해져 순수 기동으로는 우위를 만들 수 없었다. 상대 BT를 분석하니 **절대 고도 하한과 회복 기동이 없고, 고도차만 보고 따라 내려왔다.**
교전 로그 115판을 조사해 상대가 저고도에서 자멸한 사례를 확인했다. 관성 오버슛(700~732 m)을 실측 보정해 강하 목표 고도를 1,060 m로 정했다.
내부 시험 9회 중 5회가 적기 추락으로 끝났다.

## 강화학습 트랙

- **정책망**: SAC + LSTM. MLP 대비 승급 조건을 약 200회 빨리 통과
- **관측**: 3차 개정 (16 → 18 → 15차원). 접근율 항목을 추가하고, 제출 프로토콜에 맞춰 각속도를 제거
- **커리큘럼**: 7단계. 실제 서버 배치를 측정해 재구성
- **한계**: 회피·기동하는 상대(Stage 2 이후)에서 승률 0.000. 동일 조건 교전에서 RL 모델 3종은 명중 0, 규칙 기반 BT는 대미지 0.786을 기록해 규칙 기반을 제출 모델로 결정

## 회고

예선 패배 3경기는 모두 상대의 사격이 아니라 **우리 기체의 추락**이었다.
트리는 “어떻게 이길 것인가”만 판정하고 **“지금 쫓아도 되는가”**는 판정하지 않았다. 유리한 위치에서 강하하는 적을 그대로 따라가다 추락했다.
저고도 유인은 “따라 내려오는 쪽이 먼저 지면에 닿는다”를 전제로 한 전략이었고, 전제가 뒤집히자 그대로 역효과가 났다.

**다음에 바꿀 것**
- 안전은 보상이 아니라 **제약**으로 분리한다. 고도 하한과 추격 중단은 규칙 층에 두고, 학습은 전술만 담당한다
- 회복·추격 중단은 현재 고도가 아니라 `현재 고도 − 강하율 × 여유시간`의 **예측형 트리거**로 판정한다
- 단일 상대 최적화를 막기 위해 상대 풀이나 self-play로 검증한다
- 완성된 BT를 교사로 한 모방학습 초기화 후 강화학습으로 개선한다
